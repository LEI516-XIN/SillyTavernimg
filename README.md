# SillyTavernimg

末世：破晓时代酒馆助手素材包。

本仓库包含互动地图脚本、五层地图素材、末世地标数据，以及“食为天”和 Run Baby Run 的末世脚景、变量结构与界面文件。

## 互动地图脚本

互动地图脚本运行于酒馆助手的独立 iframe 面板中，可通过酒馆快捷按钮打开。主要功能包括：

- 多层级地图导航：支持全局地图、局部区域和建筑内部之间的嵌套。
- 内置导航、历史记录、地图缩放和拖拽；支持手机端显示。
- 地图点位支持地点、传送门和建筑物三种类型，可设置坐标、颜色、描述和楼层信息。
- 点击点位可生成前往地点的出行指令，支持填入输入框或直接发送。
- 提供通用地点输入按键，可在当前地图没有目标地点时手动输入。
- 支持同时管理多个地图包，并在地图包之间切换。
- 支持通过外部 JSON 地址或网络图床链接导入地图。
- 支持编写、保存和切换 CSS 面板样式。
- 地图包、浏览历史和面板设置保存在酒馆助手环境变量中。
- 脚本提供简单的 JSON 导入、URL 导入与地图操作引导。

## 末世地图数据

当前内置地图包为“末世：破晓时代”，包含：

- 5 张地图：大地图、北方基地内部图、一环、二环、三环。
- 17 个地标。
- 4 个跳转入口。
- 默认地图 ID：`map_mvvdhspx`。

地图素材位于：

- `互动地图/`
- `末世：破晓时代/地图/`

地图数据位于：

- `互动地图/末世：破晓时代.json`
- `末世：破晓时代/地图/末世：破晓时代.json`

互动地图脚本默认启用简洁浅蓝主题，并额外挂载以下功能：

- 地点输入框自动读取当前 JSON 中的地图点位和楼层名称，并可随机选择已有地点。
- 角色输入框自动读取酒馆角色卡名称，并可随机加入角色卡中的角色。
- 关闭按钮、出行弹窗、输入框和按钮使用统一浅色蓝色主题，无需额外配置 CSS。

## 配套地图生成器

`地图生成器.html` 是制作地图 JSON 的可视化工具，首次运行需要联网加载部分资源。

主要功能：

- 左侧导入图片直链、本地图片或图片文件夹。
- 中间画布按比例显示地图，可拖拽确定地标坐标。
- 右侧编辑地标名称、类型、颜色、跳转目标和楼层描述。
- 实时预览当前地图和全部点位。
- 使用跳转入口连接不同地图层级。
- 导入已有 JSON 后继续编辑，并导出符合互动地图格式的数据。

## 使用方式

在酒馆助手脚本库中新建全局脚本，启用以下导入：

```javascript
import 'https://testingcf.jsdelivr.net/gh/kayanorin/SillyTavernimg/互动地图/index.js';
```
